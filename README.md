# AMBA Protocol Study

## Overview
This project contains a theoretical study of AMBA bus architecture including AXI, AHB, APB and AXI4 vs AXI4-Lite differences.

## Topics Covered
- AMBA Bus Hierarchy
- APB Protocol
- AHB Protocol
- AXI Protocol
- Handshake mechanisms
- Real SoC integration examples

## Implementation Status
Currently focused on theoretical understanding. RTL implementation will be added in future updates.
